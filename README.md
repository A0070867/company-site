# スカイライン・テクノロジーズ 企業サイト

2016年創業のソフトウェア企業「スカイライン・テクノロジーズ」のコーポレートサイトです。
基幹システムから顧客接点まで、ソフトウェアという「見えない構造」を設計・開発するチームであることを紹介しています。

## サイト構成

`index.html` 単体で完結する静的ページです。主なセクションは以下の通りです。

- **About（私たちについて）** — 会社の価値観・沿革
- **Services（事業内容）** — プロダクト開発、クラウド基盤構築、データ・AI活用支援、UI/UXデザイン
- **Works（実績）** — 導入事例の抜粋
- **Contact** — プロジェクト相談の窓口

## ブラウザでindex.htmlを開く手順

1. このリポジトリをダウンロードまたはクローンします。
2. `index.html` を右クリックし、「プログラムから開く」からお使いのブラウザ（Chrome、Edge など)を選択します。
   - もしくは、ブラウザを起動してから `Ctrl + O`（Windows）でファイルを選択して開くこともできます。
3. ブラウザのアドレスバーに `index.html` のパスが表示され、サイトが表示されれば完了です。

インターネット接続がある場合、Google Fonts（見出し・本文フォント）が自動的に読み込まれます。
